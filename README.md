
# 🚀 Git-And-GitHub

Welcome to the **Git-And-GitHub** repository! This is a beginner-friendly and practical guide to mastering **Git** and **GitHub** — from setup to advanced workflows. Whether you're just starting or want to strengthen your version control knowledge, this repository is here to help.

---

## 📁 Repository Structure

| Sr. No. | File Name                          | Description                                                                 |
|--------:|-----------------------------------|-----------------------------------------------------------------------------|
| 1️⃣     | `Getting Started with GitHub.md`   | Introductory guide to GitHub basics, setup, and creating your first repo.  |
| 2️⃣     | `Git and GitHub.md`                | Covers differences between Git and GitHub with use cases.                  |
| 3️⃣     | `Git Behind The Scenes.md`         | Understand what happens internally when Git commands are run.              |
| 4️⃣     | `Terminology.md`                   | Key Git/GitHub terms explained for beginners.                              |
| 5️⃣     | `Branched In Git.md`               | Learn about branches, creating/switching/merging strategies.               |
| 6️⃣     | `Diff Stash And Tags.md`           | Usage of `git diff`, `git stash`, and tagging for releases.                |
| 7️⃣     | `Rebase and Reflog in Git.md`      | Explanation and examples of `git rebase` and `git reflog`.                 |

---

## 📌 Topics Covered

- ✅ What is Git & GitHub
- ✅ Installing and setting up Git
- ✅ Git configuration and commands
- ✅ Branching and merging
- ✅ Stashing and tagging
- ✅ Rebase and Reflog
- ✅ Understanding Git internals
- ✅ GitHub workflows
